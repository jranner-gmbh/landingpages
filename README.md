## Text ändern
1. Ordner öffnen → `index.html` anklicken → Stift-Symbol (rechts oben).
2. Mit Strg+F den Text suchen und nur den Text zwischen den Zeichen ändern (nichts an `<`, `>` oder `"`).
3. Unten bzw. oben rechts **Commit changes** → Netlify veröffentlicht nach ca. 30 Sekunden.
